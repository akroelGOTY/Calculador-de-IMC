# 🧮 Calculadora de IMC

<p>Uma aplicação simples para calcular o <b>IMC (Índice de Massa Corporal)</b> a partir do peso e altura <br> informados pelo usuário.</p>

---

## 📌 Sobre o projeto

Este projeto calcula o IMC utilizando a fórmula:

```

IMC = peso / (altura × altura)

```

---

## 🧠 Classificação de IMC <br>
* IMC	Classificação 
  * Menor que 18.5	Abaixo do peso
  * 18.5 – 24.9	Peso normal
    * 25 – 29.9	Sobrepeso
    * 30 ou mais	Obesidade
